## US targeting without spam
- English main content; en-US locale, US spelling where relevant, and a project RFQ CTA.
- Address real purchasing questions and explain limitations. Avoid claimed rankings, guaranteed positions, invented search volume or repeated keyword blocks.
- Use descriptive, non-stuffed alt text and image filenames. Keep a single visible H1.
- Link to the verified product page naturally. Create the proposed cross-article internal links only when the pages are live.
- Test localized URLs, canonical, hreflang reciprocity, sitemap and schema after integration.
